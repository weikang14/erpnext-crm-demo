            If it still can't connect after reconnecting, recreate the CRM's web container:

            6. 测试完恢复演示数据6. Reset the demo data

            下面的命令会清空两边的全部数据，包括测试时建的销售订单和商机。

            These commands wipe all data on both sides, including the sales orders and deals created while testing.

            cd ERP
docker compose down -v
docker compose up -d --build
docker compose exec backend bench --site localhost execute ombak_mfg.setup.demo.run
docker compose exec portal python manage.py seed_operators

cd ../CRM
docker compose -f docker-compose.yml -f docker-compose.erp.yml down -v
docker compose -f docker-compose.yml -f docker-compose.erp.yml up -d --build
docker compose exec web python manage.py seed_demo

            只重置其中一边时要注意：CRM 里已发送的商机还指向 ERPNext 的订单号，ERP 重置后这些链接会打不开。

            Resetting only one side: sent deals in the CRM still point at ERPNext order numbers, so after an ERP reset those links won't open.

            标记和备注只存在这个浏览器里，换浏览器或清除网站数据就会消失。 Marks and notes are stored only in this browser; another browser, or clearing site data, loses them.
