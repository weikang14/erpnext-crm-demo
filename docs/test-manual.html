        3. 销售 CRM

        8082

        C1：本地运行时所有访客共用同一个地址，询价表单每小时最多 5 次，超过后一小时内谁都提交不了。

        C14：请用不存在的用户名，例如 locktest。用真实账号测，会把它锁 15 分钟。

          C14 之后提前解锁：

          cd CRM && docker compose exec web python manage.py shell -c "from sales import ratelimit; ratelimit.clear('login', 'locktest')"

          4. CRM → ERPNext 串接

          8082 → 8080

          需要用第 0 节的方式（带 docker-compose.erp.yml）启动 CRM。不带它启动时，成交商机的面板显示 ERP link not configured，也不会调用 ERPNext。

            I7 和 I9 用的命令（只断开 CRM 和 ERPNext 之间的网络，ERP 本身不受影响）：

            docker network disconnect erp_crm_link ombak-crm-web-1   # I7：断开
docker network connect erp_crm_link ombak-crm-web-1      # I9：重新连接

            如果重新连接后还是连不上，重建 CRM 的 web 容器就好：

            cd CRM && docker compose -f docker-compose.yml -f docker-compose.erp.yml up -d --force-recreate web

            6. 测试完恢复演示数据

            下面的命令会清空两边的全部数据，包括测试时建的销售订单和商机。

            cd ERP
docker compose down -v
docker compose up -d --build
docker compose exec backend bench --site localhost execute ombak_mfg.setup.demo.run
docker compose exec portal python manage.py seed_operators

cd ../CRM
docker compose -f docker-compose.yml -f docker-compose.erp.yml down -v
docker compose -f docker-compose.yml -f docker-compose.erp.yml up -d --build
docker compose exec web python manage.py seed_demo

            只重置其中一边时要注意：CRM 里已发送的商机还指向 ERPNext 的订单号，ERP 重置后这些链接会打不开。

            标记和备注只存在这个浏览器里，换浏览器或清除网站数据就会消失。
